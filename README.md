# 🌅 기상 챌린지 — 설치 & 배포 가이드

내가 정한 시간에 일어나서 버튼 하나로 인증하고, 한 달 동안 가장 꾸준했던 사람이 **기상왕**이 되는 웹사이트예요.
참가자는 **링크 + 구글 계정**만 있으면 참여할 수 있고, 운영 비용은 **0원**이에요.

- 호스팅: GitHub Pages (무료)
- 로그인 · 데이터 저장: Firebase Authentication + Cloud Firestore (무료 Spark 요금제, 카드 등록 필요 없음)

소요 시간: 처음 하면 30분 정도

---

## 들어 있는 파일

| 파일 | 하는 일 |
|---|---|
| `index.html` | 웹페이지 뼈대 |
| `style.css` | 디자인 |
| `app.js` | 로그인, 인증, 랭킹, 기상왕 계산 |
| `firebase-config.js` | **내 Firebase 설정값을 붙여넣는 곳** (2단계) |
| `firestore.rules` | 보안 규칙. 부정 인증을 서버에서 막아요 (4단계) |

---

## 1단계. Firebase 프로젝트 만들기

1. https://console.firebase.google.com 에 구글 계정으로 접속합니다.
2. **프로젝트 추가**를 누르고 이름을 정합니다 (예: `wake-challenge`).
3. Google 애널리틱스는 **사용 안 함**으로 두고 만들기를 누릅니다.

## 2단계. 웹 앱 등록 → 설정값 복사

1. 프로젝트 첫 화면에서 **`</>` (웹)** 아이콘을 누릅니다.
2. 앱 닉네임을 입력하고 **앱 등록**을 누릅니다. Firebase 호스팅 체크박스는 비워두세요.
3. 화면에 나오는 `const firebaseConfig = { ... }` 안의 값 6개를 복사합니다.
4. `firebase-config.js`를 메모장으로 열고 `"여기에_붙여넣기"` 자리에 각각 붙여넣은 뒤 저장합니다.

> 이 값들은 공개되어도 괜찮아요. 데이터 보호는 4단계의 보안 규칙이 담당합니다.

## 3단계. 구글 로그인 켜기

1. 왼쪽 메뉴에서 **빌드 → Authentication → 시작하기**로 들어갑니다.
2. **로그인 방법** 탭에서 **Google**을 고르고 **사용 설정**을 켭니다.
3. 프로젝트 지원 이메일을 고르고 저장합니다.

## 4단계. 데이터베이스 만들기 + 보안 규칙 넣기

1. 왼쪽 메뉴에서 **빌드 → Firestore Database → 데이터베이스 만들기**로 들어갑니다.
2. 위치는 **asia-northeast3 (서울)**을 고르고, **프로덕션 모드**로 만듭니다.
3. 상단의 **규칙** 탭에서 기존 내용을 모두 지우고, `firestore.rules` 파일 내용을 통째로 붙여넣은 뒤 **게시**를 누릅니다.

## 5단계. GitHub Pages로 사이트 올리기

1. https://github.com 에 가입하거나 로그인합니다.
2. 오른쪽 위 **+ → New repository**를 누르고, 이름을 정한 뒤(예: `wake-challenge`) **Public**으로 만듭니다.
3. 저장소 화면에서 **Add file → Upload files**를 누르고 파일 5개(`index.html`, `style.css`, `app.js`, `firebase-config.js`, `firestore.rules`)를 끌어다 놓은 뒤 **Commit changes**를 누릅니다.
4. 저장소의 **Settings → Pages**에서 Source를 **Deploy from a branch**, Branch를 **main / (root)**로 정하고 **Save**를 누릅니다.
5. 1~2분 뒤 같은 화면 위쪽에 사이트 주소가 나옵니다. `https://내아이디.github.io/wake-challenge/` 같은 형태예요.

## 6단계. 사이트 주소를 Firebase에 등록 (안 하면 로그인 안 됨!)

1. Firebase 콘솔에서 **Authentication → 설정 → 승인된 도메인**으로 들어갑니다.
2. **도메인 추가**를 누르고 `내아이디.github.io`를 입력합니다. `https://`와 뒤의 경로는 빼고 입력하세요.

이제 사이트 주소로 들어가서 구글 로그인을 하고 닉네임과 목표 시간을 정하면 시작돼요. 🎉

## 7단계. 나를 관리자로 등록 (상품 이름 정하기용)

1. 먼저 사이트에서 로그인하고 가입을 끝냅니다.
2. Firebase 콘솔 → **Firestore Database → 데이터**로 가서 `users` 컬렉션을 열고, 내 닉네임이 있는 문서의 **문서 ID**(긴 영문·숫자)를 복사합니다.
3. 맨 왼쪽의 **+ 컬렉션 시작**을 누르고 컬렉션 ID를 `admins`로 입력합니다.
4. 문서 ID에는 방금 복사한 값을 붙여넣고, 필드는 `role` (string) = `admin`으로 넣은 뒤 저장합니다.
5. 사이트를 새로고침하면 **기상왕** 탭 아래에 **"관리자 · 상품 정하기"** 칸이 생겨요.

## 8단계. 참가자 초대

사이트 링크를 단톡방에 공유하면 끝이에요.

> **카카오톡 안에서 링크를 열면** 구글 로그인이 막혀요. 이건 구글 정책이라 어떤 사이트든 마찬가지예요.
> 그래서 사이트가 카톡 안에서 열리면 **"외부 브라우저로 열기"** 버튼을 자동으로 보여줍니다. 그 버튼을 누르거나, 크롬/사파리로 열면 돼요.
> 홈 화면에 추가해두면 앱처럼 쓸 수 있어요.

## 규칙 (사이트에 적용된 것)

| 항목 | 내용 |
|---|---|
| 목표 시간 | 각자 04:00 ~ 11:00 사이로 설정 |
| 인증 가능 시간 | 목표 **90분 전 ~ 30분 후** |
| 성공 | 목표 시간과 같거나 그 전에 인증 |
| 지각 | 목표 후 30분 안에 인증 (기록은 되지만 성공으로는 안 셈) |
| 실패 | 그날 인증 안 함 |
| 순위 | ① 성공 일수 → ② 평균 몇 분 일찍 일어났는지 → ③ 지각 적은 순 |
| 기상왕 발표 | 매달 1일부터 **기상왕** 탭에 지난달 1위가 자동으로 나옴 |

### 부정 인증 방지 (서버에서 검사)
- 인증 시각은 폰 시계가 아니라 **서버 시간**으로 기록돼요. 폰 시간을 바꿔도 소용없어요.
- 인증은 하루에 한 번만 할 수 있고, 한 번 하면 수정할 수 없어요.
- 목표 시간을 바꾸면 **다음 날부터** 적용돼요. 늦잠 잔 날 목표를 바꾸는 꼼수를 막기 위해서예요.
- 다른 사람 기록은 볼 수만 있고 고칠 수 없어요. 관리자는 기록을 삭제할 수 있어요 (콘솔에서).

> 한계: "버튼을 누른 사람이 정말 침대에서 일어났는지"까지는 확인할 수 없어요. 친구끼리 하는 챌린지니까 양심에 맡기거나, 원하면 단톡방에 기상 사진 올리기를 같이 하면 좋아요.

## 월말 운영 루틴

1. **매달 초**: 기상왕 탭 → 관리자 칸에 이번 달 상품 이름을 입력합니다.
2. **다음 달 1일 아침**: 기상왕 탭에 지난달 1위가 자동으로 나와요. 화면을 캡처하거나 링크를 단톡방에 공유하세요.
3. 상품은 카카오톡 선물하기로 직접 보내면 끝!

## 수정하고 싶을 때

- **인증 가능 시간 바꾸기**: `app.js` 위쪽의 `WINDOW_BEFORE` / `WINDOW_AFTER`와, `firestore.rules`의 `- 90`, `+ 30`을 **둘 다** 같은 숫자로 바꾸세요. 규칙은 Firebase 콘솔에서 다시 게시해야 해요.
- **파일 수정 후 반영**: GitHub 저장소에서 파일을 다시 업로드하면 1~2분 뒤 사이트에 반영돼요.

## 문제 해결

| 증상 | 해결 |
|---|---|
| "설정이 필요해요" 화면이 뜸 | `firebase-config.js`에 값을 안 넣었거나 업로드를 안 한 경우 (2단계) |
| 로그인 창이 바로 닫히거나 오류 | 6단계 승인된 도메인을 확인하세요. 카톡 안이라면 외부 브라우저로 여세요 |
| "데이터를 불러오지 못했어요" | 4단계 데이터베이스 생성과 규칙 게시를 확인하세요 |
| 인증 버튼을 눌렀는데 "저장할 수 없어요" | 인증 가능 시간이 아니거나 이미 오늘 인증한 경우예요 |

## 무료 한도

Firebase 무료 요금제(Spark)는 하루 읽기·쓰기 횟수에 한도가 있어요. 친구 수십 명 규모라면 한도에 닿을 일이 거의 없어요.
한도를 넘더라도 요금이 나가지 않고 그날만 잠시 멈춰요. 카드를 등록하지 않았기 때문이에요.
